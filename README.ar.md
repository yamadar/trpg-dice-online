# Dice & Chat

**Languages:** [English](README.md) · [日本語](README.ja.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [한국어](README.ko.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [ไทย](README.th.md) · [Türkçe](README.tr.md) · [Bahasa Indonesia](README.id.md) · [Polski](README.pl.md) · [Tiếng Việt](README.vi.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Українська](README.uk.md)

أداة رمي نرد على الإنترنت لجلسات TRPG. ارمِ النرد، احفظ قوالب قابلة لإعادة
الاستخدام، وشارك النتائج والسجل والدردشة مع فريقك في الوقت الفعلي — كل
ذلك من صفحة ثابتة بدون خلفية خادم.

**🎲 العرض المباشر:** https://yamadar.github.io/trpg-dice-online/

## الميزات

- **النرد (A)** — اختر العدد والنوع قبل كل رمية
  (`D4, D6, D8, D10, D12, D20, D100`). `D100` يرمي قطعتي d10 كرقمين،
  ويُقرأ `00` على أنه 100.
- **المعدّل (B)** — يضيف/يطرح عدداً صحيحاً إلى النتيجة.
- **النوع (C)** — `ضرر` أو `اختبار`.
- **الشخصيات** — احتفظ بعدة شخصيات (الاسم، الخلفية العامة، مذكرة خاصة،
  صورة اختيارية، قائمة القوالب، وتفضيل «تضمين المذكرة في التصدير» لكل
  شخصية)، انتقل بينها وقم بالتصدير/الاستيراد بصيغة JSON.
- **القوالب** — ادمج A + B + C باسم واحفظها لكل شخصية، وارمها بنقرة من
  القائمة.
- **خلاصة السجل والدردشة** — الرميات والدردشة في خلاصة زمنية واحدة مع
  مرشّح: الكل / الرميات / الدردشة / الملفات.
- **سجل الغرف السابقة** — تُحفظ كل جلسة سابقة؛ تصفح الخلاصة للقراءة من
  الردهة واحذف بحسب الجلسة أو الكل دفعة واحدة. لمس اسم يعرض لقطة الشخصية
  وآخر صورة معروفة.
- **الغرف على الإنترنت** — شاشتا إنشاء/انضمام منفصلتان مع رمز غرفة
  (4 أحرف على الأقل؛ تُولَّد آليًا بطول 6). يُشارك السجل والدردشة وقائمة
  اللاعبين عبر P2P؛ بعد إعادة التحميل يستضيف الحكم من جديد، أو يلتحق
  اللاعب تلقائيًا.
- **عناصر تحكم الحكم** — تغيير اسم الغرفة والرمز ضمن قسم الحكم القابل
  للطي، وزر الخروج للحكم هو «إغلاق الغرفة».
- **رميات الحكم المخفية** — يمكن للحكم إخفاء القيمة؛ يرى الآخرون فقط أنه
  وقعت رمية مخفية.
- **ألوان اللاعبين ومؤشر الكتابة** — لكل مشارك لون ثابت، ومؤشر هادئ يُظهر
  من يكتب.
- **أحداث الغرفة** — تظهر الدخول/الخروج في الخلاصة، وإغلاق الغرفة من قبل
  الحكم يُبلّغ الجميع بشكل صحيح.
- **متعدد اللغات والترجمة التلقائية** — تدعم الواجهة 19 لغة. تعرض الترجمة
  التلقائية الاختيارية رسائل اللاعبين الآخرين بلغة واجهتك؛ تفضّل واجهة
  Chrome Translator على الجهاز وترجع إلى واجهة REST بدون مفتاح من
  [MyMemory](https://mymemory.translated.net/) عند تعذّرها. انقر «الأصلي»
  على رسالة مترجمة لرؤية النص كما أُرسل.

## كيف تعمل المشاركة عبر الإنترنت

يستخدم التطبيق **اتصالات WebRTC P2P عبر [PeerJS](https://peerjs.com/)**.
يكون منشئ الغرفة (الحكم) هو المضيف؛ يتصل البقية مباشرة بالحكم الذي يقوم
بترحيل الحالة المشتركة. لا تمر أي بيانات عبر خادم تابع لهذا المشروع.
لكون النظام P2P، تبقى الغرفة فعّالة فقط ما دامت صفحة الحكم مفتوحة.

## مجموعة التقنيات

- [Vite](https://vite.dev/) + [React 19](https://react.dev/) + TypeScript
- [PeerJS](https://peerjs.com/) (WebRTC P2P)

- GitHub Pages + GitHub Actions (الاستضافة)

## الإعداد (مُرحِّل TURN)

يحتاج WebRTC إلى مُرحِّل TURN لربط اللاعبين الذين تحجب شبكتهم UDP أو
تستخدم NAT متماثلًا (شائع في شبكات Wi-Fi العامة). افتراضيًا، يعتمد
التطبيق على خوادم TURN العامة المجانية من Open Relay Project — تكفي
للاستخدام العادي لكنها «بأفضل جهد». للحصول على مُرحِّل موثوق، انسخ
`.env.example` إلى `.env` واضبط:

- `VITE_TURN_URLS` — عناوين TURN مفصولة بفواصل. أضف إدخال `turns:` عبر
  TCP/443 لكي يعمل عند حجب UDP.
- `VITE_TURN_USERNAME` — اسم مستخدم TURN.
- `VITE_TURN_CREDENTIAL` — بيانات اعتماد TURN (كلمة المرور).

**ملاحظة أمنية:** يقوم Vite بتضمين جميع متغيرات `VITE_*` داخل حزمة
الإنتاج، لذا فإن أي بيانات اعتماد TURN تضبطها هنا ستكون مرئية لأي شخص
يفتح الصفحة. للحدّ من خطر إساءة الاستخدام، استعمل بيانات اعتماد TURN
قصيرة الأجل / مؤقتة (مثل نمط بيانات الاعتماد المحدودة زمنيًا عبر
TURN REST API) ومارس قيود الجانب المزود — الأصول المسموح بها، تصفية
عناوين IP، أو الحصص الشهرية. لا تعِد استخدام بيانات اعتماد إنتاج طويلة
الأجل هنا.

لاستخدامها في نشر GitHub Pages، أضفها كأسرار للمستودع ومرّرها في خطوة
البناء داخل `.github/workflows/deploy.yml`. الخيارات المجانية: الباقة
المجانية من [Metered](https://www.metered.ca/) أو استضافة
[coturn](https://github.com/coturn/coturn) ذاتيًا.

## النشر

الدفع إلى `main` يُشغّل سير عمل GitHub Actions
(`.github/workflows/deploy.yml`): فحص، اختبار، بناء، ونشر على GitHub
Pages. مسار الأساس في الإنتاج هو `/trpg-dice-online/`؛ يمكن تجاوزه عبر
متغير البيئة `BASE_PATH` عند الاستضافة في مكان آخر.
