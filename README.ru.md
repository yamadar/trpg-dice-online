Онлайн-кости для настольных ролевых игр. Кидайте кубики, сохраняйте
шаблоны и делитесь результатами, историей и чатом с группой в реальном
времени — всё это со статической страницы, без серверной части.

**🎲 Демо:** https://yamadar.github.io/trpg-dice-online/

## Возможности

- **Кости (A)** — выбирайте количество и тип перед каждым броском
  (`D4, D6, D8, D10, D12, D20, D100`). `D100` кидает два d10 как цифры;
  `00` читается как 100.
- **Модификатор (B)** — `+/-` к результату.
- **Вид (C)** — `урон` или `проверка`. Урон отображается как
  `{шаблон}: {значение} урона`; проверка — `Результат проверки
  «{шаблон}»: {значение}`.
- **Персонажи** — храните несколько персонажей (имя, открытая
  предыстория, личная заметка, опциональный портрет, список шаблонов и
  персональная настройка «включать заметку в экспорт»), переключайтесь
  между ними и экспортируйте/импортируйте как JSON.
- **Шаблоны** — соберите A + B + C с именем и сохраняйте по персонажам;
  быстрый бросок в один клик.
- **Лента истории и чата** — броски и чат в одной хронологической
  ленте с фильтром Всё / Броски / Чат / Файлы.
- **История прошлых комнат** — каждая сессия сохраняется; читайте
  ленту только для чтения из лобби и удаляйте по сессиям или сразу всё.
  Тап по имени показывает снимок персонажа и последний известный портрет.
- **Онлайн-комнаты** — отдельные экраны «Создать» / «Присоединиться» с
  кодом комнаты (минимум 4 символа; автоматически создаются 6-значные).
  История, чат и список игроков синхронизируются P2P; после перезагрузки
  ведущий перехостит, игрок переподключится автоматически.
- **Управление ведущим** — переименование и смена кода спрятаны в
  свёрнутый блок; выход у ведущего — «Закрыть комнату».
- **Скрытые броски ведущего** — ведущий может скрыть значение; другие
  видят, что был скрытый бросок.
- **Цвета игроков и индикатор набора** — каждый получает стабильный
  цвет; ненавязчивый индикатор показывает, кто печатает.
- **События комнаты** — входы/выходы появляются в ленте, закрытие
  комнаты ведущим аккуратно уведомляет всех.
- **Многоязычность и авто-перевод** — интерфейс поддерживает 19 языков.
  Дополнительный авто-перевод чата отображает сообщения других игроков на
  языке вашего интерфейса; предпочтительно используется встроенный
  Chrome Translator API, при недоступности — бесключевой REST API
  [MyMemory](https://mymemory.translated.net/). Нажмите «Оригинал» на
  переведённом сообщении, чтобы увидеть исходный текст.

## Как работает обмен онлайн

Приложение использует **WebRTC P2P через [PeerJS](https://peerjs.com/)**.
Создатель комнаты (ведущий) выступает хостом; остальные подключаются
напрямую к ведущему, который ретранслирует общее состояние. Данные не
проходят через серверы проекта. Из-за P2P-схемы комната жива, пока
страница ведущего открыта.

## Конфигурация (TURN-ретранслятор)

WebRTC нужен TURN-ретранслятор, чтобы соединять игроков, чья сеть
блокирует UDP или использует симметричный NAT (часто в публичных Wi-Fi).
По умолчанию приложение использует бесплатные публичные TURN-серверы
Open Relay Project — годятся для случайного использования, но «best
effort». Для надёжного ретранслятора скопируйте `.env.example` в `.env`
и задайте:

- `VITE_TURN_URLS` — TURN-URL через запятую. Включите запись `turns:`
  через TCP/443, чтобы работало там, где блокирован UDP.
- `VITE_TURN_USERNAME` — имя пользователя TURN.
- `VITE_TURN_CREDENTIAL` — учётные данные TURN (пароль).

**Безопасность:** Vite встраивает все переменные `VITE_*` в production-
бандл, поэтому любые учётные данные TURN, заданные здесь, видны всем,
кто открывает страницу. Чтобы снизить риск злоупотреблений, используйте
короткоживущие / временные учётные данные TURN (например, шаблон с
ограниченным временем жизни через TURN REST API) и настройте
ограничения со стороны провайдера — разрешённые origin'ы, IP-фильтры,
месячные квоты. Не используйте здесь долгоживущие production-учётки.

Для деплоя на GitHub Pages добавьте их как секреты репозитория и
передайте на шаге сборки в `.github/workflows/deploy.yml`. Бесплатные
варианты: бесплатный тариф [Metered](https://www.metered.ca/) или
самостоятельный хостинг [coturn](https://github.com/coturn/coturn).

## Деплой

Push в `main` запускает workflow GitHub Actions
(`.github/workflows/deploy.yml`): lint, тесты, сборка и публикация на
GitHub Pages. Базовый путь в проде — `/trpg-dice-online/`; переопределяется
переменной `BASE_PATH` при размещении в другом месте.
