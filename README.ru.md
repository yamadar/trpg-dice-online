## Почему выбрать его для следующей сессии

- **Поделитесь кодом — и начинаем бросать.** Мастер создаёт комнату и зачитывает 4–6-символьный код; остальные просто вводят его. Никаких аккаунтов, подтверждений по email, никакой регистрации.
- **Броски остаются между вами.** Чистый P2P через WebRTC: броски и чат идут напрямую от устройства к устройству, не через наш сервер.
- **Чувствует себя как дома на телефоне на столе.** Мобильный first-вёрстка, ставится как PWA на iOS и Android, запускается на весь экран.
- **Знает 19 языков и сам переводит чат.** Немецкая жрица может перешутиться с японским разбойником, никто не выпадает из погружения.
- **Спроектировано так, чтобы хотелось вернуться.** Персонажи, паттерны, темы, размер шрифта и прошлые сессии хранятся локально — приложение ощущается как *ваш* кубический ларец, а не как чужой киоск.

## Сессия за 30 секунд

1. **Мастер:** откройте демо, нажмите **Комната → Создать** и зачитайте код.
2. **Игроки:** откройте демо, нажмите **Комната → Войти** и введите код.
3. **Все:** бросайте, переписывайтесь, вместе встречайте первую естественную 20-ку.

Мастер — хост. Пока его вкладка открыта, комната жива. Закрыл вкладку — сессия завершена. Прошлые комнаты остаются локально, чтобы можно было перечитать журнал позже.

## Что в кубическом ларце

### Кубики, которые читаются с первого взгляда

`d4 · d6 · d8 · d10 · d12 · d20 · d100`, с количеством, знаковым модификатором и типом **урон / проверка**, который формулирует результат так, как сказали бы за столом — *«Результат проверки Восприятия: 18»*, *«Двуручный меч: 11 урона»*. Каждая выпавшая грань показывается как маленькая силуэтная иконка, соответствующая форме кубика, — мгновенно считывается.

### Паттерны — любимые ходы в один тап

Сохраните `2D6 + 3 — урон` под именем вроде *«Двуручный меч»* и повторите бросок одним тапом в следующем раунде. Паттерны принадлежат персонажам, поэтому два ПС на одном устройстве держат свои наборы отдельно.

### Персонажи с портретом, заметками и своими паттернами

У одного игрока может быть несколько ПС. У каждого — имя, общий бэкграунд, личная заметка, которую видите только вы, опциональный портрет, отдельный список паттернов и индивидуальная настройка *«включать заметку в экспорт»*. Экспорт в JSON для бэкапа; импорт на другом устройстве, чтобы привести ПС на следующую сессию. Когда вы действуете как персонаж, имя отображается как `Персонаж (Игрок)`.

### Одна лента для бросков *и* чата

Броски и чат живут в одной хронологической ленте с фильтром **Всё / Броски / Чат / Файлы**. Автодополнение `@` цепляет нужного игрока; `@all` достучится до всех. Если приложить картинку к сообщению, она будет автоматически уменьшена перед отправкой.

### Прошлые комнаты для перечитывания

Каждая прошлая сессия сохраняется локально как долговременный журнал. Из лобби можно открыть старую комнату в режиме только-чтения; тап по имени игрока в старой ленте покажет тогдашний снимок персонажа и последний известный портрет. Целую комнату (чат, броски, картинки) можно выгрузить одним ZIP.

### Инструменты мастера

Мастер может бросать **в скрытую** — остальные видят только *«сделан скрытый бросок»*, но не число. Раздел мастера собирает переименование комнаты и регенерацию кода под раскрывающейся секцией, а кнопка выхода мастера называется **Закрыть комнату** — чтобы было ясно, что это завершает сессию для всех.

### Интерфейс на 19 языках и авто-перевод чата

UI на 19 языках. Опциональный авто-перевод чата использует Chrome Translator API на устройстве, когда он доступен, и откатывается на не требующий ключа [MyMemory](https://mymemory.translated.net/) REST API. Нажмите **Оригинал** на переведённом сообщении, чтобы увидеть исходный текст.

### Мелочи, которые приятно замечать

Стабильный цвет на игрока, ненавязчивый индикатор печати, события входа / выхода в ленте, переключение тем, регулируемый размер шрифта и аккуратное оповещение, когда мастер закрывает комнату.

## Установить на телефон (PWA)

Сайт — это Progressive Web App, его можно добавить на главный экран iOS и Android и запускать в полноэкранном режиме — без интерфейса браузера и почти мгновенно.

- **Android (Chrome):** откройте демо, в меню браузера выберите **Установить приложение** (или *Добавить на главный экран*).
- **iOS (Safari):** откройте демо, нажмите «Поделиться» и выберите **На экран «Домой»**.

Service worker пре-кэширует оболочку приложения, чтобы оно стартовало мгновенно. Сами комнаты — P2P через WebRTC, и им нужен живой интернет.

**Ориентация экрана:** манифест не блокирует и не переопределяет ориентацию, поэтому установленная PWA следует настройке авто-поворота / блокировки на устройстве (например, на Android при выключенном авто-повороте приложение остаётся в текущей ориентации, даже если вы повернёте телефон).

## Как устроена онлайн-связь

Комнаты используют **WebRTC peer-to-peer** через [PeerJS](https://peerjs.com/). Создатель комнаты (мастер) — это хост; каждый другой игрок подключается напрямую к мастеру, и мастер ретранслирует общее состояние. Никакие игровые данные не проходят через серверы, принадлежащие этому проекту. Поскольку это P2P, комната жива только пока вкладка мастера открыта.

```bash
npm run build    # продакшн-сборка в dist/
```

## Настройка (опциональный TURN-релей)

WebRTC нужен TURN-релей, чтобы подключать игроков, чья сеть блокирует UDP или использует симметричный NAT (часто в кафе / общественном Wi-Fi). По умолчанию приложение откатывается на бесплатные публичные TURN от Open Relay Project — для случайного использования сойдёт, но без гарантий.

Для надёжного релея скопируйте `.env.example` в `.env` и заполните:

- `VITE_TURN_URLS` — список TURN URL через запятую. Включите запись `turns:` на TCP/443, чтобы работало там, где UDP заблокирован.
- `VITE_TURN_USERNAME` — имя пользователя TURN.
- `VITE_TURN_CREDENTIAL` — учётные данные / пароль TURN.

> **Безопасность:** Vite встраивает каждую переменную `VITE_*` в продакшн-бандл, поэтому TURN-учётки, заданные здесь, видны любому, кто загрузит страницу. Используйте короткоживущие / эфемерные TURN-учётки (например, паттерн с временными credential через TURN REST API) и настройте ограничения на стороне провайдера — разрешённые origin, IP-фильтры, месячные квоты. Не переиспользуйте здесь долгоживущие продакшн-учётки.

Чтобы использовать их при деплое на GitHub Pages, добавьте как секреты репозитория и пробросьте на этапе сборки в `.github/workflows/deploy.yml`. Бесплатные варианты: бесплатный план [Metered](https://www.metered.ca/) или self-hosted [coturn](https://github.com/coturn/coturn).

## Деплой

Пуш в `main` запускает workflow GitHub Actions (`.github/workflows/deploy.yml`), который выполняет lint, тесты, сборку и публикует на GitHub Pages. Продакшн base path — `/trpg-dice-online/`; переопределите переменной окружения `BASE_PATH` для другого хостинга.
