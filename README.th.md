## คุณสมบัติ

- **ลูกเต๋า (A)** — เลือกจำนวนและชนิดก่อนทุกครั้งที่ทอย
  (`D4, D6, D8, D10, D12, D20, D100`) `D100` ใช้ d10 สองลูกเป็นหลักเลข,
  `00` อ่านเป็น 100
- **ค่าปรับ (B)** — เพิ่ม/ลดเลขจำนวนเต็มเข้ากับผล
- **ประเภท (C)** — `ความเสียหาย` หรือ `ทดสอบ`
- **ตัวละคร** — เก็บตัวละครหลายตัว (ชื่อ, พื้นเพสาธารณะ, บันทึกส่วนตัว,
  รูปภาพเสริม, รายการรูปแบบ และค่าตั้ง "รวมบันทึกเมื่อส่งออก" แยกตามตัวละคร)
  สลับได้และส่งออก/นำเข้าเป็น JSON
- **รูปแบบ** — รวม A + B + C ตั้งชื่อและบันทึกตามตัวละคร ทอยซ้ำได้จาก
  รายการในแตะเดียว
- **ฟีดประวัติและแชท** — การทอยและแชทอยู่ในฟีดเดียว มีตัวกรอง ทั้งหมด /
  ทอย / แชท / ไฟล์
- **ประวัติห้องที่ผ่านมา** — ทุกเซสชันถูกเก็บเป็นบันทึก เปิดอ่านอย่างเดียวจาก
  ล็อบบี้ ลบทีละเซสชันหรือทั้งหมดได้ แตะชื่อแสดงสแนปช็อตและรูปล่าสุด
- **ห้องออนไลน์** — หน้าจอ "สร้าง" / "เข้าร่วม" แยกกัน รหัสห้องอย่างน้อย 4
  ตัวอักษร (สุ่มเป็น 6) ประวัติ แชทและรายชื่อแบ่งปันผ่าน P2P รีโหลด
  จะกลับมาโฮสต์ (GM) หรือเข้าใหม่ (ผู้เล่น) โดยอัตโนมัติ
- **การตั้งค่าสำหรับ GM** — เปลี่ยนชื่อห้องและรหัสห้องอยู่ในส่วน GM พับเก็บได้
  ปุ่มออกของ GM คือ "ปิดห้อง"
- **ทอยซ่อนของ GM** — GM ซ่อนค่าได้ คนอื่นเห็นแค่ว่ามีการทอยซ่อน
- **สีผู้เล่นและตัวบ่งบอกการพิมพ์** — ผู้เล่นแต่ละคนมีสีคงที่ และเครื่องหมาย
  ระบุว่าใครกำลังพิมพ์
- **เหตุการณ์ห้อง** — เข้า/ออกแสดงในฟีด เมื่อ GM ปิดห้อง ทุกคนจะได้รับการ
  แจ้งเตือนอย่างเหมาะสม
- **หลายภาษาและแปลอัตโนมัติ** — UI รองรับ 19 ภาษา การแปลอัตโนมัติแบบ
  เลือกได้จะแสดงข้อความของผู้เล่นคนอื่นในภาษาของอินเทอร์เฟซของคุณ โดยใช้
  Chrome Translator API บนอุปกรณ์เป็นหลัก หากใช้ไม่ได้จะใช้
  [MyMemory](https://mymemory.translated.net/) REST API แบบไม่ต้องใช้คีย์
  เป็นทางเลือกสำรอง แตะ "ต้นฉบับ" บนข้อความที่แปลแล้วเพื่อดูข้อความตามที่ส่งมา

## วิธีการแชร์ออนไลน์

แอปใช้ **การเชื่อมต่อ WebRTC P2P ผ่าน [PeerJS](https://peerjs.com/)**
ผู้สร้างห้อง (GM) เป็นโฮสต์; คนอื่นเชื่อมต่อกับ GM โดยตรง ซึ่งจะส่งต่อ
สถานะที่ใช้ร่วมกัน ไม่มีข้อมูลใดผ่านเซิร์ฟเวอร์ของโปรเจกต์ ห้องจะใช้ได้เฉพาะ
ตอนที่ GM เปิดหน้าไว้เท่านั้น

## การตั้งค่า (TURN รีเลย์)

WebRTC ต้องใช้ TURN รีเลย์เพื่อเชื่อมต่อผู้เล่นที่อยู่บนเครือข่ายที่บล็อก
UDP หรือใช้ NAT แบบสมมาตร (พบบ่อยใน Wi-Fi สาธารณะ) โดยค่าเริ่มต้น แอปจะ
ใช้เซิร์ฟเวอร์ TURN สาธารณะแบบฟรีของ Open Relay Project ซึ่งเหมาะกับการ
ใช้งานทั่วไปแต่เป็นแบบ "best effort" หากต้องการรีเลย์ที่เสถียร ให้คัดลอก
`.env.example` เป็น `.env` แล้วตั้งค่า:

- `VITE_TURN_URLS` — URL ของ TURN คั่นด้วยจุลภาค ใส่รายการ `turns:`
  ผ่าน TCP/443 เพื่อให้ใช้งานได้บนเครือข่ายที่บล็อก UDP
- `VITE_TURN_USERNAME` — ชื่อผู้ใช้ TURN
- `VITE_TURN_CREDENTIAL` — ข้อมูลรับรอง TURN (รหัสผ่าน)

**ข้อควรระวังด้านความปลอดภัย:** Vite จะฝังตัวแปร `VITE_*` ทุกตัวลงใน
บันเดิลโปรดักชัน ดังนั้นข้อมูลรับรอง TURN ที่คุณตั้งไว้ที่นี่จะปรากฏแก่ทุกคน
ที่เปิดหน้าเว็บ เพื่อลดความเสี่ยงจากการถูกใช้ในทางที่ผิด ให้ใช้ข้อมูลรับรอง
TURN ที่อายุสั้น / ชั่วคราว (เช่น รูปแบบข้อมูลรับรองแบบจำกัดเวลาผ่าน
TURN REST API) ร่วมกับขีดจำกัดฝั่งผู้ให้บริการ (ออริจินที่อนุญาต ฟิลเตอร์ IP
หรือโควต้ารายเดือน) อย่านำข้อมูลรับรองโปรดักชันที่อายุยาวมาใช้ซ้ำที่นี่

หากต้องการใช้ในการดีพลอย GitHub Pages ให้เพิ่มเป็น Secrets ของรีโพและส่ง
ผ่านขั้นตอนบิลด์ใน `.github/workflows/deploy.yml` ตัวเลือกฟรี ได้แก่ แผน
ฟรีของ [Metered](https://www.metered.ca/) หรือโฮสต์
[coturn](https://github.com/coturn/coturn) เอง

## การดีพลอย

การ push ไปยัง `main` จะกระตุ้น GitHub Actions workflow
(`.github/workflows/deploy.yml`) ซึ่ง lint, ทดสอบ, บิลด์ และเผยแพร่ไปยัง
GitHub Pages base path คือ `/trpg-dice-online/`; เปลี่ยนได้ด้วยตัวแปร
`BASE_PATH` เมื่อโฮสต์ที่อื่น
