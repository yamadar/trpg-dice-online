โปรแกรมทอยลูกเต๋าออนไลน์สำหรับเซสชัน TRPG: ทอยลูกเต๋า บันทึกรูปแบบที่ใช้ซ้ำ
และแบ่งปันผลทอย ประวัติ และแชทกับเพื่อนแบบเรียลไทม์ ทั้งหมดจากเพจสแตติก
ที่ไม่มีเซิร์ฟเวอร์แบ็กเอนด์

**🎲 เดโม:** https://yamadar.github.io/trpg-dice-online/

## คุณสมบัติ

- **ลูกเต๋า (A)** — เลือกจำนวนและชนิดก่อนทุกครั้งที่ทอย
  (`D4, D6, D8, D10, D12, D20, D100`) `D100` ใช้ d10 สองลูกเป็นหลักเลข,
  `00` อ่านเป็น 100
- **ค่าปรับ (B)** — เพิ่ม/ลดเลขจำนวนเต็มเข้ากับผล
- **ประเภท (C)** — `ความเสียหาย` หรือ `ทดสอบ`
- **ตัวละคร** — เก็บตัวละครหลายตัว (ชื่อ, พื้นเพสาธารณะ, บันทึกส่วนตัว,
  รูปภาพเสริม, รายการรูปแบบ และค่าตั้ง "รวมบันทึกเมื่อส่งออก" แยกตามตัวละคร)
  สลับได้และส่งออก/นำเข้าเป็น JSON
- **รูปแบบ** — รวม A + B + C ตั้งชื่อและบันทึกตามตัวละคร ทอยซ้ำได้จาก
  รายการในแตะเดียว
- **ฟีดประวัติและแชท** — การทอยและแชทอยู่ในฟีดเดียว มีตัวกรอง ทั้งหมด /
  ทอย / แชท / ไฟล์
- **ประวัติห้องที่ผ่านมา** — ทุกเซสชันถูกเก็บเป็นบันทึก เปิดอ่านอย่างเดียวจาก
  ล็อบบี้ ลบทีละเซสชันหรือทั้งหมดได้ แตะชื่อแสดงสแนปช็อตและรูปล่าสุด
- **ห้องออนไลน์** — หน้าจอ "สร้าง" / "เข้าร่วม" แยกกัน รหัสห้องอย่างน้อย 4
  ตัวอักษร (สุ่มเป็น 6) ประวัติ แชทและรายชื่อแบ่งปันผ่าน P2P รีโหลด
  จะกลับมาโฮสต์ (GM) หรือเข้าใหม่ (ผู้เล่น) โดยอัตโนมัติ
- **การตั้งค่าสำหรับ GM** — เปลี่ยนชื่อห้องและรหัสห้องอยู่ในส่วน GM พับเก็บได้
  ปุ่มออกของ GM คือ "ปิดห้อง"
- **ทอยซ่อนของ GM** — GM ซ่อนค่าได้ คนอื่นเห็นแค่ว่ามีการทอยซ่อน
- **สีผู้เล่นและตัวบ่งบอกการพิมพ์** — ผู้เล่นแต่ละคนมีสีคงที่ และเครื่องหมาย
  ระบุว่าใครกำลังพิมพ์
- **เหตุการณ์ห้อง** — เข้า/ออกแสดงในฟีด เมื่อ GM ปิดห้อง ทุกคนจะได้รับการ
  แจ้งเตือนอย่างเหมาะสม
- **หลายภาษา** — UI รองรับ 19 ภาษา

## วิธีการแชร์ออนไลน์

แอปใช้ **การเชื่อมต่อ WebRTC P2P ผ่าน [PeerJS](https://peerjs.com/)**
ผู้สร้างห้อง (GM) เป็นโฮสต์; คนอื่นเชื่อมต่อกับ GM โดยตรง ซึ่งจะส่งต่อ
สถานะที่ใช้ร่วมกัน ไม่มีข้อมูลใดผ่านเซิร์ฟเวอร์ของโปรเจกต์ ห้องจะใช้ได้เฉพาะ
ตอนที่ GM เปิดหน้าไว้เท่านั้น

## เทคโนโลยี

- [Vite](https://vite.dev/) + [React 19](https://react.dev/) + TypeScript
- [PeerJS](https://peerjs.com/) (WebRTC P2P)
- [Vitest](https://vitest.dev/) (ทดสอบหน่วย)
- GitHub Pages + GitHub Actions (โฮสติ้ง)

## การพัฒนา

```bash
npm install      # ติดตั้งแพ็กเกจ
npm run dev      # รันเซิร์ฟเวอร์ dev
npm test         # รันเทส
npm run lint     # ลินต์
npm run build    # บิลด์โปรดักชันไป dist/
```

## การดีพลอย

การ push ไปยัง `main` จะกระตุ้น GitHub Actions workflow
(`.github/workflows/deploy.yml`) ซึ่ง lint, ทดสอบ, บิลด์ และเผยแพร่ไปยัง
GitHub Pages base path คือ `/trpg-dice-online/`; เปลี่ยนได้ด้วยตัวแปร
`BASE_PATH` เมื่อโฮสต์ที่อื่น
