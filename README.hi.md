# TRPG ऑनलाइन पासे

**Languages:** [English](README.md) · [日本語](README.ja.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [한국어](README.ko.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [ไทย](README.th.md) · [Türkçe](README.tr.md) · [Bahasa Indonesia](README.id.md) · [Polski](README.pl.md) · [Tiếng Việt](README.vi.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Українська](README.uk.md)

टेबलटॉप TRPG सत्रों के लिए ऑनलाइन पासे फेंकने वाला उपकरण। पासे फेंकें,
दोबारा उपयोग होने वाले पैटर्न सहेजें, और परिणाम, इतिहास और चैट को अपनी
टीम के साथ रीयल-टाइम साझा करें — सब कुछ बिना बैकएंड के एक स्टैटिक पेज से।

**🎲 लाइव डेमो:** https://yamadar.github.io/trpg-dice-online/

## विशेषताएँ

- **पासे (A)** — हर रोल से पहले संख्या और प्रकार चुनें
  (`D4, D6, D8, D10, D12, D20, D100`)। `D100` दो d10 को अंकों के रूप में
  फेंकता है; `00` को 100 पढ़ा जाता है।
- **संशोधक (B)** — परिणाम पर `+/-` पूर्णांक संशोधक लागू करें।
- **प्रकार (C)** — `क्षति` या `परीक्षण`।
- **पात्र** — कई पात्र रखें (नाम, सार्वजनिक पृष्ठभूमि, निजी मेमो,
  वैकल्पिक चित्र, पैटर्न सूची, और प्रति पात्र "निर्यात में मेमो शामिल करें"
  सेटिंग), इनके बीच स्विच करें, और JSON के रूप में निर्यात/आयात करें।
- **पैटर्न** — A + B + C को नाम देकर पात्र के अनुसार सहेजें; सूची से एक
  टैप में फेंकें।
- **इतिहास और चैट फ़ीड** — रोल और चैट एक ही समयानुक्रम फ़ीड में, फ़िल्टर:
  सभी / रोल / चैट / फ़ाइलें।
- **पिछले कक्षों का इतिहास** — हर सत्र सहेजा जाता है; लॉबी से रीड-ओनली
  फ़ीड देखें और प्रति सत्र या सब हटाएँ। फ़ीड में नाम टैप करने पर उस समय
  का पात्र स्नैपशॉट और अंतिम ज्ञात चित्र दिखता है।
- **ऑनलाइन कक्ष** — अलग-अलग बनाएँ/शामिल हों स्क्रीन, कक्ष कोड कम से कम 4
  वर्ण (स्वतः उत्पन्न 6)। इतिहास, चैट और खिलाड़ी सूची P2P से साझा होते हैं;
  रिफ़्रेश पर GM फिर से होस्ट करता है और खिलाड़ी स्वतः फिर से शामिल हो जाता है।
- **GM नियंत्रण** — कक्ष का नाम और कोड बदलना संक्षिप्त GM अनुभाग में, और
  GM का बाहर निकलने वाला बटन "कक्ष बंद करें"।
- **GM की छिपी रोल** — GM मान छिपा सकता है; अन्य को केवल यह दिखता है कि
  छिपा रोल हुआ।
- **खिलाड़ी रंग और टाइप संकेतक** — हर भागीदार को स्थिर रंग; हल्का संकेतक
  दिखाता है कौन टाइप कर रहा है।
- **कक्ष घटनाएँ** — प्रवेश/निकास फ़ीड में दर्ज होते हैं, GM कक्ष बंद करने
  पर सबको सही तरीक़े से सूचित किया जाता है।
- **बहुभाषी और स्वतः अनुवाद** — इंटरफ़ेस 19 भाषाओं का समर्थन करता है।
  वैकल्पिक स्वतः अनुवाद अन्य खिलाड़ियों की चैट को आपकी UI भाषा में दिखाता है;
  पहले डिवाइस के Chrome Translator API का उपयोग करता है, उपलब्ध न होने पर
  बिना-कुंजी [MyMemory](https://mymemory.translated.net/) REST API पर लौटता
  है। अनूदित संदेश पर «मूल» टैप करके वास्तव में भेजा गया पाठ देख सकते हैं।

## ऑनलाइन साझा करने का तरीक़ा

ऐप **[PeerJS](https://peerjs.com/) के माध्यम से WebRTC P2P कनेक्शन** का
उपयोग करता है। कक्ष निर्माता (GM) होस्ट होता है; बाकी सीधे GM से जुड़ते हैं,
GM साझा स्थिति आगे भेजता है। कोई डेटा इस परियोजना के सर्वर से नहीं गुज़रता।
P2P होने के कारण कक्ष केवल तब तक चालू रहता है जब तक GM का पेज खुला रहता है।

## कॉन्फ़िगरेशन (TURN रिले)

WebRTC को उन खिलाड़ियों को जोड़ने के लिए TURN रिले की आवश्यकता होती है
जिनका नेटवर्क UDP को ब्लॉक करता है या सिमेट्रिक NAT पर है (सार्वजनिक
Wi-Fi में आम)। डिफ़ॉल्ट रूप से ऐप Open Relay Project के मुफ़्त सार्वजनिक
TURN सर्वर पर लौटता है — आकस्मिक उपयोग के लिए पर्याप्त लेकिन «best
effort»। विश्वसनीय रिले के लिए `.env.example` को `.env` में कॉपी करके
यह सेट करें:

- `VITE_TURN_URLS` — कॉमा से अलग की गई TURN URLs। UDP ब्लॉक होने पर भी
  काम चले इसलिए TCP/443 पर एक `turns:` प्रविष्टि शामिल करें।
- `VITE_TURN_USERNAME` — TURN उपयोगकर्ता नाम।
- `VITE_TURN_CREDENTIAL` — TURN क्रेडेंशियल (पासवर्ड)।

**सुरक्षा सूचना:** Vite हर `VITE_*` वैरिएबल को प्रोडक्शन बंडल में इनलाइन कर
देता है, इसलिए यहाँ सेट किए गए TURN क्रेडेंशियल पेज खोलने वाले हर व्यक्ति को
दिखाई देंगे। दुरुपयोग का जोखिम कम करने के लिए कम-अवधि / अस्थायी TURN
क्रेडेंशियल का उपयोग करें (उदा. TURN REST API से समय-सीमित क्रेडेंशियल
पैटर्न) और प्रदाता-स्तरीय सीमाएँ लागू करें — अनुमत origin, IP फ़िल्टरिंग,
मासिक कोटा। लंबे समय तक मान्य प्रोडक्शन क्रेडेंशियल यहाँ दोबारा उपयोग न करें।

GitHub Pages पर तैनाती में इनका उपयोग करने के लिए इन्हें रिपॉज़िटरी सीक्रेट
के रूप में जोड़ें और `.github/workflows/deploy.yml` के बिल्ड चरण में पास
करें। मुफ़्त विकल्प: [Metered](https://www.metered.ca/) का मुफ़्त टियर, या
[coturn](https://github.com/coturn/coturn) को स्वयं होस्ट करना।

## तैनाती

`main` पर पुश GitHub Actions वर्कफ़्लो
(`.github/workflows/deploy.yml`) को चलाता है: लिंट, परीक्षण, बिल्ड और
GitHub Pages पर प्रकाशन। प्रोडक्शन base path `/trpg-dice-online/` है;
कहीं और होस्ट करने पर `BASE_PATH` एनवायरनमेंट वैरिएबल से बदलें।
